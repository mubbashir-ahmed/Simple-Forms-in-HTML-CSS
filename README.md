# Simple Forms in HTML & CSS

A collection of seven (7) beautifully designed, responsive forms built with pure HTML and CSS. This project demonstrates clean form design patterns and modern CSS styling techniques without any JavaScript dependencies.

Check out the live version of the project here: [https://simple-forms-indol.vercel.app/](https://simple-forms-indol.vercel.app/)

## 📋 Features

- **Pure HTML & CSS** - No JavaScript required
- **Responsive Design** - Works seamlessly across different screen sizes
- **Modern UI** - Clean and professional form designs
- **Reusable Styles** - Global styles and CSS variables for consistency
- **Easy Navigation** - Index page with links to all forms

## 🎨 Forms Included

1. **Login Form** - User authentication interface with email and password fields
2. **Signup Form** - New user registration with multiple input fields
3. **Registration Form** - Comprehensive registration form with detailed user information
4. **Need A Help Form** - Support request form for user assistance
5. **Customer Feedback Form** - Collect customer reviews and feedback
6. **Get Quotes Form** - Request pricing or quotation information
7. **Subscribe Form** - Newsletter or service subscription form

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge, etc.)
- A code editor (VS Code, Sublime Text, etc.) - optional for customization

### Installation & Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/mubbashir-ahmed/Simple-Forms-in-HTML-CSS.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Simple-Forms-in-HTML-CSS
   ```

3. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local development server:
     ```bash
     npx http-server
     ```

4. **Browse forms**
   - Click on any form button on the index page to view individual forms
   - Use the "Back" button on each form to return to the main page

## 🎨 Customization

The project uses CSS variables defined in `css/Variables.css` for easy customization. You can modify colors, fonts, and other design tokens to match your brand:

```css
/* Example: Modify in css/Variables.css */
:root {
    --primary-color: #your-color;
    --secondary-color: #your-color;
    /* ... other variables */
}
```
